# Machine Learning

A collection of practical implementations and experiments covering important **Machine Learning concepts**, data preprocessing techniques, feature engineering, and regression algorithms.

This repository is created to practice Machine Learning concepts through hands-on projects, notebooks, and datasets.

---

## 📚 Topics Covered

### 1. Exploratory Data Analysis (EDA)
- Data understanding
- Data visualization
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Distribution analysis
- Correlation analysis

### 2. Data Preprocessing
- Handling missing values
- Handling categorical data
- Encoding techniques
- Feature scaling
- Data cleaning
- Train-test split

### 3. Feature Engineering
- Feature transformation
- Feature construction
- Feature selection
- Column Transformer
- Function Transformer
- Power Transformer
- Pipeline

### 4. Handling Missing Data
- Mean/Median imputation
- Mode imputation
- Categorical data imputation
- Missing value analysis

### 5. Outlier Detection & Treatment
- IQR method
- Z-score method
- Outlier removal
- Outlier capping
- Understanding the effect of outliers

### 6. Linear Regression
- Simple Linear Regression
- Multiple Linear Regression
- Model training
- Model prediction
- Regression evaluation
- Visualization of regression planes

### 7. Model Evaluation
Regression metrics covered:
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- R² Score
- Z-score based analysis

### 8. Data Handling & Web Data
- Working with CSV files
- Working with JSON data
- Working with APIs
- Web Scraping
- Data collection and preprocessing
